- [ ] permanent business identity/name gate is clear;
- [ ] repository is audited for secrets, customer data, licenses and stale endpoints;
- [ ] claims/pricing/legal text are reconciled to the current business;
- [ ] privacy/security/customer-data controls pass;
- [ ] dependency and secret scans pass;
- [ ] any public demo data is synthetic;
- [ ] a human GO/HOLD/NO-GO decision is recorded.

Never add credentials, tokens, MFA codes, real customer data or private internal materials.

# Security Policy

Do not publish vulnerabilities, secrets, credentials, API keys, tokens, MFA codes, real customer data or exploitable details in public issues, PRs, logs or screenshots.

Use GitHub private vulnerability reporting when available or the owner's established private channel. Do not access data that is not yours, perform destructive/DoS testing, exfiltrate data or socially engineer users.

Critical/high unresolved findings block reuse or deployment. Exposed secrets must be rotated/revoked and handled under the OpenCK Incident Response, Breach & Legal Hold Runbook.
